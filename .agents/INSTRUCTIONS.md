Стек:
- Python 3.12, Django 6
- Bootstrap, Alpine, Chart, HTMX, Sortable (локально, без CDN)
- Docker
- PostgreSQL

Правила вызова команд:
- Все команды, связанные с python, выполняй с активированным виртуальным окружением (venv). Либо использовать полный путь к интерпретатору: ./.venv/Scripts/python
- Для проверки проекта используй запущенный Docker контейнер web

Запреты:
- Не устанавливай библиотеки в глобальное окружение python
